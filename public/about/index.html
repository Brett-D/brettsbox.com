About

I'm Brett. I like bringing old hardware back to life, running my own services, and building things that are a little more ambitious than they need to be.

Scroll

Hi there

I'm a maker at heart. Give me something that's been written off, a dead robot vacuum, a retired office PC, a printer that “never prints right”, and I'll want to know how it works and what else it could do. Most of what I build starts that way: an old thing, a new idea, and a lot of evenings at the bench.

Right now that means a Roomba from 2007 that maps the house with a stereo camera, a homelab that keeps our photos and files under our own roof, and a 3D printer that makes the brackets, mounts and enclosures that hold it all together.

How I work

  • Measure, don't guess. A multimeter reading or a drift test beats a hunch every time.
  • Write it down. Wiring diagrams, dead ends and numbers go in the notebook (now this site), so future me doesn't repeat past me's mistakes.
  • Safety first, especially with batteries. Fuses at the source, no bypassed protection circuits, and a healthy respect for lithium.
  • Share it. The code is on GitHub so anyone with an old Roomba can skip the parts I got wrong.

Building with an AI pair-programmer

A lot of this is built with AI pair-programming help. I set the goals, make the calls, hold the soldering iron and the multimeter, and test everything on the real hardware; the AI helps me write and review code, dig through datasheets and service manuals, draw schematics and keep these notes tidy. It's made projects like a full ROS 2 navigation stack feasible for one person working in the evenings, and I've learned a huge amount along the way.

This website was built the same way: I decided what it should say and how it should feel, and GitHub Copilot wrote the HTML, CSS and the small Python script that generates it.
